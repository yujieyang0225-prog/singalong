# MNH26SVR
Neuromorphic singing voice recognition

NeuroTUM Hackathon 2026, Innatera × Sofilab challenge: real-time sing-along detection on the Innatera Pulsar EVK.

## Layout
- Repo root: code (Talamo pipelines, training, firmware kernels)
- `Hackathon/`: team Obsidian vault with project overview, tasks, ideas, research notes and the challenge song set. Open this folder as a vault in Obsidian and start at `Home.md`.

## Clone
```bash
git clone git@github.com:nc-fortiss/MNH26SVR.git
```
Then in Obsidian choose **Open folder as vault** and select `MNH26SVR/Hackathon`. The community plugin *Obsidian Git* is optional (auto pull/push).
